GROOVOCADO WEBSITE

Upload index.html, style.css, app.js and the assets folder together to your website public folder (often httpdocs or public_html). Keep their relative paths unchanged. Back up your existing website before replacing files.

Open index.html to preview locally. Google Fonts and YouTube require an internet connection.

Languages: Slovenian is the default. English uses ?lang=en and the SI/EN switch.

Editing: index.html contains the page text, contact details, video links and downloads. data-si and data-en hold the two language versions. style.css controls appearance. app.js handles language switching and the mobile menu.

Replace assets/hero.webp for the main photo and the group JPGs for press downloads. The technical rider is assets/Groovocado-Tech_Rider.pdf.

This is a static website: no installation or build step is required.
